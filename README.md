# 📊 Superstore Sales Analysis & Forecast Dashboard

This project focuses on analyzing sales performance and predicting future trends using Power BI.

-----

## 📁 Dataset
- Superstore Sales Dataset 

-----

## 🛠️ Tools Used
- Excel (Data Cleaning)
- Power BI (Dashboard & Visualization)
- DAX (Calculated Columns & Measures)
- Power BI Forecasting (Time Series Analysis)
- Table Visualization (Detailed Data View)
- Zoom Slider (Trend Analysis & Filtering)

-----

## 🔄 Workflow
1. Imported dataset from Kaggle
2. Cleaned and structured data using Excel
3. Loaded data into Power BI
4. Created data model and relationships
5. Used DAX for calculations
6. Built interactive dashboard
7. Applied 15-day sales forecasting
8. Created table view for detailed insights
9. Used zoom slider for focused time analysis

-----

## 📈 Dashboard Features
- KPI Cards (Sales, Profit, Quantity, Avg Delivery)
- Sales trends (monthly & yearly)
- Category and sub-category analysis
- Shipping mode insights
- State-wise performance
- 15-day forecast using time series analysis
- Zoom slider for analyzing specific time ranges
- Table view for detailed data exploration

-----

## 🔍 Key Insights
- Sales increase towards the end of the year
- Standard Class is the most used shipping mode
- Office Supplies contribute highest sales
- Few states generate major revenue
